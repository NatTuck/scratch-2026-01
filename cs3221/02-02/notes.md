
## Recurrance Relation Examples

Stooge Sort was: T(n) = 3T(2n/3) + \Theta(1)

Merge sort: T(n) = 2T(n/2) + \Theta(n)

- n log n

Merge sort with insertion instead of merge: 2T(n/2) + \Theta(n^2)

- n^2 log n

Merge sort (no merge): T(n) = 2T(n/2) + \Theta(1)

Sum a linked list: T(n) = 1T(n - 1) + \Theta(1)

Binary search: T(n) = 1T(n/2) + \Theta(1)
